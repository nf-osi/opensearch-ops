# nf-datasets golden set — dataset documentation

Companion notes for [`golden.yaml`](golden.yaml), the relevance ground truth for the
**nf-datasets** SearchIndex (`syn75081630`, source table `syn50913342`, 173 rows). Per-field
semantics and the case schema are in the header of `golden.yaml`; how cases are produced is in
the [`generate-goldens`](../../.claude/skills/generate-goldens/SKILL.md) skill. This file
records dataset-level provenance and **coverage gaps** — queries deliberately not turned into
cases, and why.

Each source row is a curated Synapse dataset (title, assay / `measurementTechnique`,
`dataType`, disease manifestation, species, keywords, description).

## `id_field`: `id`

The Synapse entity id — 100% filled and unique across all 173 source rows. No accession/DOI
column is clean or dense enough to serve as the key, and `id` is preferable to falling back to
the index's own `rowId`. The runner matches hits on this value.

## Case provenance (the `source:` field)

| `source` | Origin |
| --- | --- |
| `agent-generated` | Discovery cases generated by the `generate-goldens` skill; `relevant` sets derived from the **source table** (`measurementTechnique` / `dataType` / manifestation / `species` `HAS`, plus title/keyword `LIKE`), not from search. |

30 cases — 28 topical / 2 known-item (both exact-title sanity checks: `synodos-nf2-drug-screen`,
`cnf-spatial-transcriptomics`).

## Domain themes covered

- **Assays / modalities:** bulk RNA-seq, single-cell RNA-seq, WES, WGS, ATAC-seq, methylation
  array, ChIP-seq, spatial transcriptomics, proteomics/mass-spec, ELISA/antibody.
- **Data types:** copy-number variants, germline variants, somatic variants, drug screens,
  combination/synergy screens.
- **Imaging:** immuno-histology (IHC/ICC) and radiology (MRI) kept as **separate** cases.
- **Disease / manifestation:** MPNST, plexiform NF, cutaneous NF, schwannomatosis, vestibular
  schwannoma / NF2, low-grade glioma.
- **Model systems / species:** zebrafish retina regeneration, mouse models, iPSC-derived,
  organoids, cfDNA liquid biopsy.

## Notable judgment calls

- **False friend — `dataType: immunoassay`** over-matches: it tags zebrafish EdU-proliferation
  and imaging rows, not only antibody assays. The `elisa-antibody` head was grounded on the
  actual ELISA/epitope/titer titles instead, with the exclusion noted in the case.
- **Imaging split:** immuno-histology separated from radiology; EdU-proliferation "images"
  excluded from the histology set as functional assays.
- **Variant pools** (germline/somatic) are dominated by per-caller pipeline outputs
  (DeepVariant / Mutect2 / Strelka / FreeBayes); heads pick the canonical/representative output
  rather than every near-duplicate pipeline row.

## Coverage gaps — attributes that could not ground queries

- **`assay`** is ~5% filled (near-empty), so it is a weak seed — `measurementTechnique` /
  `dataType` were used instead.
- **`countryOfOrigin`, `visualizeDataOn`, `modelSystemName`** are too sparse to seed queries.
