# nf-studies golden set — dataset documentation

Companion notes for [`golden.yaml`](golden.yaml), the relevance ground truth for the
**nf-studies** SearchIndex (`syn75081633`, source table `syn52694652`, 355 rows). Per-field
semantics and the case schema are in the header of `golden.yaml`. This file records
dataset-level provenance and **coverage gaps** — queries deliberately not turned into cases,
and why.

Each source row is an NF research study/project (studyName, summary, disease manifestation,
data types, funding agency, initiative/consortium, institutions).

## `id_field`: `studyId`

The study's Synapse id — 100% filled and unique (355/355), identical to the redundant `id`
column. The runner matches hits on this value; every hit also carries `studyName` for the
display comments.

## Domain themes covered

- **Manifestation / tumor types:** MPNST, plexiform NF, cutaneous NF, schwannoma, optic glioma,
  low-grade glioma, meningioma, atypical neurofibroma. (JMML has no dedicated case; its studies
  still surface via `dhart-spore` and `mek-inhibitor`.)
- **Assays / data types & methods:** drug screen, RNA-seq / gene expression, imaging/MRI,
  proteomics, single-cell, iPSC, organoid, CRISPR/base-prime editing, ASO / exon-skipping /
  nonsense suppression, cfDNA liquid biopsy, plasma WGS.
- **Funding programs / consortia:** NTAP, CDMRP (DoD), Young Investigator Award, Synodos,
  DHART-SPORE, Gene Therapy Initiative, Vision Restoration Initiative.
- **Therapeutics & phenotypes:** MEK inhibitor / selumetinib, cognition/memory, NF-related pain.

## Notable judgment calls

- **ntap-mri (PORTALS-3975):** replaced the former `jmml` case. Pool is NTAP-funded studies whose
  studyName/summary mentions MRI/imaging/magnetic resonance. `syn17100988` leads because it's
  NTAP-funded and built explicitly around MRS/fMRI/BOLD/MRI methods.
- **Synodos:** two rows (`syn25999950`, `syn51117783`) are Synodos-initiative studies with
  non-Synodos titles — excluded from the head in favor of the five explicitly "Synodos …"
  titled studies.
- **Meningioma / schwannoma false-friend guard:** for the `HAS`-based pools, studies with the
  phenotype *in the title* were promoted over broad NF2-tumor studies that merely carry the tag.
- **`mek-inhibitor` and `single-cell-sequencing`** used `LIKE` pools that over-match generic
  mentions; heads were restricted to titles explicitly about the concept.

## Coverage gaps — columns not turned into queries

High-cardinality free-text / identifier columns and status flags were deliberately left out:
`grantDOI`, `studyFileviewId`, `relatedStudies`, date columns, `alternateDataRepository`
accessions, and study-status flags — none yields a clean topical or known-item query.

> These are **drafts for SME review** — especially the topical relevant-set ordering and the
> false-friend exclusions above. Run with `python3 benchmark/run.py studies`.
